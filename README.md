# Drawing App 🎨

A simple and intuitive Android application that allows users to create digital sketches, customize brush settings, and save their masterpieces directly to their device. Built with Kotlin and modern Android development practices.

## 🚀 Features

- **Free-hand Drawing:** Smooth and responsive drawing experience on a digital canvas.
- **Customizable Brush:**
  - Adjust brush size dynamically via an interactive slider.
  - Choose from a palette of preset colors.
  - Full-featured **Color Picker** for infinite color possibilities.
- **Background Integration:** Import any image from your device's gallery to use as a background for your drawings.
- **Edit Controls:** 
  - **Undo:** Quickly correct mistakes by removing the last drawn stroke.
  - **Clear Canvas:** Start fresh with a single tap.
- **Export to Gallery:** Save your creations as high-quality images directly to the `Pictures/DrawingApp` folder on your device.
- **Modern Permissions:** Seamlessly handles Android runtime permissions, including specific support for Android 13+ (Tiramisu) media access.

## 🛠️ Built With

- **Kotlin** - Primary programming language.
- **XML** - For UI layout design.
- **Coroutines** - For asynchronous background tasks (saving images).
- **AmbilWarna** - A powerful color picker library for Android.
- **AndroidX & Material Components** - For a modern and consistent UI.

## 📥 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/apollocked/DrawingApp.git
   ```
2. Open the project in **Android Studio**.
3. Build and run the app on an emulator or a physical Android device.

## 📝 How to Use

1. **Draw:** Simply touch and drag your finger on the canvas area.
2. **Change Color:** Tap on the preset color circles or the color picker icon to select a new stroke color.
3. **Change Brush Size:** Click the brush icon and use the slider to adjust thickness.
4. **Import Background:** Tap the gallery icon to select an image from your device.
5. **Save:** Tap the save icon to export your drawing to your local storage.
